# Media

| Fichier | Ce qu'on voit | Comment le refaire |
|---|---|---|
| `fenetre.png` | La fenêtre sur le hp, sortie muette : cinq voies, la Sortie et le tracé entrée / sortie de Micro 1. « Aucun signal » sous Micro 1 parce que le micro du hp est coupé dans le système. | Sur le hp : micro rallumé (`pactl set-source-mute @DEFAULT_SOURCE@ 0`), `TABLE_DE_MIXAGE_DEBUG=muet TABLE_DE_MIXAGE_CAPTURE=/tmp/fenetre.ppm ./target/release/table-de-mixage`, puis `magick /tmp/fenetre.ppm media/fenetre.png` |
| `visite-musique.png` | La visite guidée, étape 5 : tout est voilé sauf la voie Musique (avec « Test cri »), la bulle dessous. | Sans toucher à l'écran : `kwin_wayland --virtual --width 1366 --height 768 --exit-with-session ./dedans.sh`, où `dedans.sh` lance `Xwayland :77`, la table avec `LIBGL_ALWAYS_SOFTWARE=1 XDG_CONFIG_HOME=<dossier vide> WAYLAND_DISPLAY=`, donne le focus à la fenêtre (XSetInputFocus), envoie 4 fois → par XTest et capture avec `import -window root`. |
| `telephone-micro-table.png` | L'appli « Micro table » sur le J7, connectée : adresse, code, état, Démarrer/Arrêter, tracé et niveau du micro. | `telephone/construire.sh`, `adb install -r`, Démarrer, puis un faux PC qui envoie le code ; `adb exec-out screencap -p`, réduit de moitié. |
| `telephone-filtres.png` | Le bas de l'écran : Anti-bruit, Coupe-cri, Limiteur, les quatre seuils et « Apprendre le bruit », recopiés depuis la table. | Comme au-dessus, après avoir fait défiler. |
| `windows-visite.png` | La même table sous Windows 11 (hp-win, 1920×1080), construite par `construire.bat /ci`, au premier lancement : la visite s'ouvre sur « Bienvenue ». | Sur hp-win : `tdm-gui.ps1` lancé par `schtasks /it` (dossier `APPDATA` vide, `TABLE_DE_MIXAGE_DEBUG=muet`), capture `CopyFromScreen` DPI-aware, puis recadrage sur la fenêtre. |
| `windows-dossier.png` | Le dossier « Table de mixage » sur le bureau de hp-win : le raccourci à l'icône fader, LISEZMOI, Micro table.apk et `programme\`. | `ranger.ps1` (sur hp-win, depuis `dist\Table de mixage` de `construire.bat /ci`) puis `voir.ps1` par `schtasks /it`, capture recadrée. |
